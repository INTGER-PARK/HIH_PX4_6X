[INPUT_FLOW]
servo_actual: DYNAMIXEL node publishes ROS2 servo_angle(rad,IDs1..4) -> listen_and_speak_ros -> /fmu/in/servo_angle(px4_msgs/ServoAngle) -> uXRCE-DDS -> uORB servo_angle -> MOB. Freshness uses Pixhawk local uORB reception hrt time, NOT source timestamp (clock domains may differ).
motor_thrust: active control allocator final/clamped per-motor physical thrust[N] -> uORB thrust_command[4] -> MOB. MOB does NOT interpret normalized actuator_motors.control or vehicle_thrust_setpoint as N.
state: uORB vehicle_odometry: q,pose_frame,velocity_frame,velocity,angular_velocity,velocity_variance,timestamp_sample,reset_counter. Raw H-Flow is not force input; its effect is only through EKF fused velocity.
gating: uORB vehicle_status(armed),vehicle_land_detected(landed),parameter_update.

[MODEL]
state: v_B=CoM/body-origin linear velocity expressed body FRD; omega_B=body angular velocity FRD.
R_LB=rotation body B -> local L from PX4 matrix::Quatf/Dcmf(vehicle_odometry.q).
velocity conversion:
 if velocity_frame==BODY_FRD: v_B=velocity.
 if velocity_frame==NED or FRD(local): v_B=R_LB^T*velocity_L.
 else force input invalid.
 attitude valid iff pose_frame in {NED,FRD}, quaternion finite, norm>0.5.
 velocity requires finite velocity and finite velocity_variance (variance value is not thresholded).

M=blockdiag(m*I3,J_B)
p=[p_v;p_w]=[m*v_B;J_B*omega_B]
g_L=[0,0,CONSTANTS_ONE_G]; g_B=R_LB^T*g_L
b_v=f_act_B + m*g_B - m*(omega_B cross v_B)
b_w=tau_act_B - omega_B cross (J_B*omega_B)
p_dot=b+w_ext_B
vehicle_acceleration/angular_acceleration are NOT observer inputs.

[SECOND_ORDER_EXTENDED_MOMENTUM_OBSERVER]
Independent 3-axis force observer and 3-axis torque observer; states p_hat,w_hat.
e=p-p_hat
p_hat_dot=b+w_hat+L1*e
w_hat_dot=L2*e
L1=2*zeta*wn; L2=wn^2
error characteristic polynomial per axis=s^2+2*zeta*wn*s+wn^2.
reset: p_hat=current measured p; w_hat=0; error=0; initialized=true.
invalidate: all state=0; initialized=false.

[DISCRETIZATION_EXACT_CODE_EQUIVALENT]
method=bilinear/Tustin, variable dt, independently per axis; h=dt/2;l1=2*zeta*wn;l2=wn^2;D=1+h*l1+h^2*l2.
rp=(1-h*l1)*p_hat_k+h*w_hat_k+dt*(b_k+l1*p_k)
rw=-h*l2*p_hat_k+w_hat_k+dt*l2*p_k
p_hat_{k+1}=(rp+h*rw)/D
w_hat_{k+1}=(-h*l2*rp+(1+h*l1)*rw)/D
e_{k+1}=p_k-p_hat_{k+1}
Reject if uninitialized/nonfinite/dt<=0/wn<=0/zeta<=0/D<=0/nonfinite result. Wrapper additionally accepts dt only in [0.0005,0.05] s.

[ACTUATOR_WRENCH]
For motor i=0..3, alpha_i=actual servo angle[rad], T_i=thrust_command[i][N].
d_i=[sx_i*sin(alpha_i)/sqrt(2),sy_i*sin(alpha_i)/sqrt(2),-cos(alpha_i)]
f_i=T_i*d_i
r_i=[px_i*arm/sqrt(2),py_i*arm/sqrt(2),z_offset]
tau_i=r_i cross f_i + sigma_i*kappa*T_i*d_i
f_act=sum(f_i);tau_act=sum(tau_i)
constants: m_default=4.0kg;arm=0.181m;z_offset=-0.005m;kappa=0.01m;J_default=diag(0.0192,0.02125,0.0282)kgm2;offdiagonal defaults=0.
index table:
i0/M1/Servo1/CW: (px,py)=(+1,-1),(sx,sy)=(+1,-1),sigma=+1,zero_d=(0,0,-1)
i1/M2/Servo2/CCW:(-1,-1),(-1,-1),sigma=-1,zero_d=(0,0,-1)
i2/M3/Servo3/CW: (-1,+1),(-1,+1),sigma=+1,zero_d=(0,0,-1)
i3/M4/Servo4/CCW:(+1,+1),(+1,+1),sigma=-1,zero_d=(0,0,-1)
These x/y and tilt signs are user-confirmed. Do not infer/reorder/change them.

freshness defaults: odom<=0.1s,thrust<=0.1s,servo<=0.1s based on local reception.
common_valid=PMOB_EN && valid_parameters && fresh_odom && valid_attitude && fresh_thrust && fresh_servo && (!PMOB_ARM_ONLY||armed).

[LIMITATIONS]
No F/T sensor and no ground truth. Estimate conflates true external/contact wrench with model residual. Errors include mass/J/CoM, command-to-thrust calibration(proxy prop data), motor/prop/DShot lag, lack of RPM/current feedback, servo delay/timestamp mismatch, aero drag, rotor interaction,ground effect,and EKF/H-Flow velocity error. Contact point cannot be uniquely recovered from CoM wrench without extra information. No compensation/tare/learned model/drag correction/ground-effect correction.
